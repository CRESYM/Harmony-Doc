
## How to Contact Us?

Harmony is an open-source research framework for power system modeling, OPF, and hybrid AC/DC system analysis.  
We welcome any user feedback, bug reports, or developer contributions.

As a user, please feel free to:

- **Create a GitHub issue** for bug reports or feature requests  
- Contact us directly via email: **A.Lekic@tudelft.nl; Robert.dimitrovski@tennet.eu**

If you are interested in contributing to Harmony, you may want to consult:

- [Project Structure and Governance](https://cresym.eu/harmony/)

For collaboration inquiries, research cooperation, or technical discussions,  
please contact:

**info@cresym.eu**
