Detailed Description

Standard numeric constants and matrix utility functions.

Provides physical constants, sign helpers, vector/matrix conversions, and basic complex-matrix arithmetic used throughout the solver.

Park A0 map of an n-port abc admittance (paper eq.

9).

Y_minus is Yabc(j(ω−ωo)), Y_plus is Yabc(j(ω+ωo)). Each port is 3×3 abc; the result is 2×2 dq per port (size 2n × 2n). Coupling blocks C± are not included (Tier 1). Matrices whose size is not a multiple of 3 are returned unchanged (Y_minus).

Effective dq admittance Yeff (paper eq.

18) for an n-port abc Y.

Y_m3, Y_m1, Y_p1, Y_p3 are Yabc at ω−3ωo, ω−ωo, ω+ωo, ω+3ωo. Yeff = A0(ω) − C−(ω) A0(ω−2ωo)⁻¹ C+(ω−2ωo) − C+(ω) A0(ω+2ωo)⁻¹ C−(ω+2ωo).
