void MMC::update_MMC ( double  Vm,
double  theta,
double  Pac,
double  Qac,
double  Vdc,
double  Pdc 
)

Set operating point.

Update MMC operating point and controller references.

Pac/Pdc use MMC machine signs (see MMC.cpp).

Parameters
VmAC voltage magnitude [V peak phase].
thetaAC voltage phase angle [rad].
PacActive power [W], MMC machine convention: positive = export to AC (AC current leaving the converter).
QacReactive power [VAr], same sign convention as Pac (standard dq Q).
VdcDC voltage [V].
PdcDC power [W], MMC machine convention: positive = import from DC (DC current entering the converter). For a lossless inverter, Pac and Pdc are both positive.

When applying MatACDC/Harmony OPF results, negate network injections: Pac = -ps, Qac = -qs, Pdc = -pn (see PowerFlow::make_OPF).
