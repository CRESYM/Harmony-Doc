Detailed Description

MIMO impedance-based stability assessment via unified MNA.

All port dimensions are derived at runtime from Bus::getPinNumber(), so the implementation handles 1-pin (DC scalar), 2-pin (dq AC) and 3-pin (abc AC) buses without any hard-coded dimension assumptions.
